# Research resources

Store reusable research here; put project-specific plans and status in
[[brain/projects/youtube-mcp/overview|the project notes]] instead.

## Resource areas

- `youtube-api/` — official YouTube Data API behavior, quota, and OAuth notes.
- `mcp/` — MCP protocol and SDK references.
- `agent-skills/` — team skill documentation and usage notes.
- `algorithms/` — reusable algorithm research relevant to project requirements.

## Adding a research note

1. Start from [[brain/resources/note-template|the research-note template]].
2. Record a traceable source, creation date, applicable requirement IDs, and
   issue or PR references (or state that none are known).
3. Summarize findings in your own words and explain their relevance to YouTube
   MCP; do not copy source material wholesale.
4. Add at least one useful wikilink to a related project note or resource.
5. Keep notes in the most relevant resource subfolder and link them from
   [[brain/index|the Second Brain index]] when they are important to active work.

This convention keeps external research traceable and connected to project
decisions. No research notes have been added yet.

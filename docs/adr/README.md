# Architecture Decision Records

Record a significant choice only after the team has made it. The repository currently has
no accepted ADRs; open questions remain listed in [`docs/srs.md`](../srs.md) and
[`docs/architecture/overview.md`](../architecture/overview.md).

## Workflow

1. Copy [`template.md`](template.md) to `NNNN-short-title.md`.
2. Record the actual context, decision, alternatives, consequences, and status.
3. Link at least one existing, relevant, distilled Second Brain note using its real
   Obsidian note name. Do not invent a note or create an ADR with an unresolved decision.
4. Submit the ADR through a PR. Update the architecture/SRS/traceability documents when
   the accepted choice changes them.

# Desktop OAuth grants

Status. Proposed for team review on 2026-11-28.

Request read-only PKCE consent first. The playlist workflow prepares the
separate write grant only when needed and verifies both grants select
the same YouTube channel. Explicit MCP confirmation remains a separate
step before mutation. Native stores hold refresh tokens. POSIX also
supports opt-in user-only file storage. Team and course review must
approve this interpretation of the incremental consent requirement.

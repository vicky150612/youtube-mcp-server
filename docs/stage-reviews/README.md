# Stage reviews

This directory is the canonical location for stage reviews (`SB-02`, ADR 0004): one file per
stage, `stage-N-review.md`. Do not mark a stage complete until its required deliverables,
evaluations, tests and review are present. Each member writes their own reflections; nobody
writes another member's reflections for them unless that member explicitly agrees to a
reflection generated from the repository record, which must then be labelled as such.

| Stage | Review | Status |
|---|---|---|
| 1 | [stage-1-review.md](stage-1-review.md) | All three member sections complete; team summary to be agreed at stage close |

## Review template

```markdown
# Stage N review

- Status: Pending | Complete
- Date:
- Participants:
- Related requirements:

## <Member> — <area>

**Work completed** · **What worked** · **What did not** · **Outstanding problems** ·
**Lessons** · **Changes for the next stage**

## Team summary
```
